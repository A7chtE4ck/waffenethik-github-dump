# Ethische Checkliste für Entwickler:innen

Bevor du an einem militärischen oder dual-use Projekt mitarbeitest, prüfe:

- [ ] **Zweck:** Wofür wird das System konkret eingesetzt?
- [ ] **Recht:** Ist die Entwicklung, der Export und der Einsatz rechtlich zulässig?
- [ ] **Zielgruppe:** Kann das System gegen Zivilpersonen eingesetzt werden?
- [ ] **Autonomie:** Welche Entscheidungen trifft das System selbst?
- [ ] **Menschliche Kontrolle:** Kann ein Mensch jede kritische Entscheidung prüfen, verweigern, stoppen oder deaktivieren?
- [ ] **Vorhersehbarkeit:** Ist das Verhalten in relevanten Situationen getestet und erklärbar?
- [ ] **Unterscheidung:** Kann das System militärische Ziele zuverlässig von Zivilpersonen und zivilen Objekten unterscheiden?
- [ ] **Verhältnismäßigkeit:** Werden mögliche zivile Schäden bewertet und begrenzt?
- [ ] **Fehlerverhalten:** Was passiert bei Sensorausfall, Datenfehlern, Manipulation oder Kommunikationsverlust?
- [ ] **Dokumentation:** Sind Entscheidungen, Tests, Versionen, Freigaben und Eingriffe auditierbar?
- [ ] **Verantwortlichkeit:** Ist vor dem Einsatz klar, wer entscheidet, überwacht und haftbar ist?
- [ ] **Unabhängige Prüfung:** Gibt es ethische, rechtliche und technische Reviews außerhalb des Projektteams?
- [ ] **Missbrauchsschutz:** Gibt es technische und vertragliche Maßnahmen gegen unerlaubte Nutzung?
- [ ] **Einsatzbeschränkungen:** Sind Zieltyp, Dauer, Ort, Umfang und Einsatzbedingungen begrenzt?
- [ ] **Whistleblowing:** Kann ich Bedenken sicher anmelden oder mich zurückziehen?
- [ ] **Persönliche Grenze:** Würde ich die konkrete Funktion öffentlich erklären und verantworten wollen?

# Entscheidungsregel

Wenn eine der folgenden Fragen mit **Nein** beantwortet wird, ist die Mitarbeit mindestens sehr problematisch:

- Kann das System im vorgesehenen Einsatz rechtlich und ethisch kontrolliert verwendet werden?
- Bleiben Menschen für die entscheidenden Urteile über Gewalt verantwortlich?
- Können Zivilpersonen ausreichend geschützt werden?
- Kann ich die technische Rolle, die Risiken und die Verantwortung offen erklären?
